# Mature Concept Template

Use this for concept files under `docs/concept/mature/<domain>/`.

```md
# <Concept Name>

## Summary

One short paragraph describing what this concept governs and why it exists.

## Canonical Design

Describe the accepted model. Use ASCII diagrams when structure or lifecycle
matters.

## Rules & Boundaries

- State ownership rules.
- State invariants implementation must preserve.
- State explicit non-goals or prohibited designs.
- Link related concepts when useful.

## Follow-up Guidance

Explain how future SOWs, implementation, reviews, migrations, and status updates
should use this concept.
```

Keep mature concepts concise. Prefer several focused concept files over one
large mixed authority file.
